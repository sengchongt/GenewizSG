# GENEWIZ Account Manager Website

A static customer-facing website for a GENEWIZ account manager. It is designed to work without a build step, so it can be previewed locally and published with GitHub Pages.

## Preview

Open `index.html` directly in a browser, or run a simple local server from this folder:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Customize Before Publishing

- Contact details are set to `sengchong.teo@azenta.com` and `+65-81128827`.
- Update territory notes or consultation links if you want to add them later.
- Confirm corporate brand, logo, trademark, and compliance requirements before sharing publicly.
- Replace the stock lab image if you have an approved GENEWIZ or Azenta asset.

## Publish With GitHub Pages

1. Create a GitHub repository.
2. Push these files to the repository.
3. In GitHub, open **Settings > Pages**.
4. Select the main branch and root folder as the Pages source.
5. Save and wait for the Pages URL to become available.
